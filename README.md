# Filmorate

Filmorate — это бэкенд-сервис на Java/Spring, реализующий «кинопоиск для своих»: социальную сеть вокруг оценки фильмов, где пользователи могут ставить оценки, просматривать рейтинги и находить, что посмотреть на основе предпочтений своих друзей.

## Функциональность

### Основные возможности

- Управление пользователями: создание, обновление, удаление, хранение списка друзей.
- Управление фильмами: добавление, обновление, удаление, хранение ключевых метаданных (название, описание, дата выхода, длительность, рейтинг MPA, жанры).
- Оценка фильмов: пользователи ставят лайки/оценки фильмам, формируя их популярность.
- Друзья и социальная составляющая: добавление в друзья и просмотр фильмов, понравившихся друзьям.
- Формирование рейтингов: выбор популярных фильмов на основе количества оценок/лайков.

## Архитектура и модель данных

Приложение реализовано как REST-сервис с чётким разделением слоёв:

- Контроллеры — принимают HTTP-запросы и возвращают ответы в формате JSON.
- Сервисный слой — бизнес-логика работы с пользователями, фильмами, лайками и друзьями.
- Хранилище/DAO — работа с базой данных или in-memory-хранилищем (в ранних версиях проекта).

Ключевые сущности:

- **User** — пользователь сервиса (id, имя, логин, email, дата рождения, друзья).
- **Film** — фильм (id, название, описание, дата релиза, длительность, рейтинг MPA, жанры, список пользователей, поставивших лайки).

## Стек технологий

- Java 11+.
- Spring Boot.
- Maven.
- Lombok.
- JDBC / Spring JDBC / H2 / PostgreSQL.
- JUnit 5, Mockito для тестирования.
- Postman для ручной проверки API.
